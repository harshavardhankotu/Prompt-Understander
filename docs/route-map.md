# Route Map (Phase A)

## Public Routes
- `/`: Home Page (Hero & Categories)
- `/login`: Auth Login
- `/register`: Auth Registration
- `/how-it-works`: Platform Overview

## Onboarding
- `/onboarding/role`: User role selection

## Buyer Routes
- `/buyer/dashboard`: Personal dashboard
- `/buyer/requirements/new`: Dynamic "Post a Problem" flow

## Provider Routes
- `/provider/dashboard`: Bid feed and active jobs

## Enterprise Routes
- `/enterprise/dashboard`: Procurement overview

## Admin Routes
- `/admin`: Platform stats and management

## QA & Demo
- `/qa`: Central testing dashboard
- `/qa/test-users`: Demo account switcher
- `/qa/test-scenarios`: Pre-defined test flows
